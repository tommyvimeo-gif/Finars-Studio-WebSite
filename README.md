# Finars Studio WebSite

Modern redesign of the **FIN ARS** architectural studio website (www.finars.si).

## Features
- Fully responsive (mobile + desktop)
- Animated backgrounds
- Image zoom / lightbox on hover & click
- Project gallery with category filters
- Project detail subpages
- Modern dark architecture-inspired design

## Pages
- `index.html` – Home
- `projekti.html` – Projects gallery
- `projekti/hisa-podvine.html` – Example project detail
- `storitve.html` – Services
- `o-nas.html` – About / Team
- `novice.html` – News
- `kontakt.html` – Contact

## How to view
Open `index.html` in a browser or deploy to any static host (GitHub Pages, Netlify, Vercel…).

## Original company
FIN ARS d.o.o. – Center za arhitekturo, Zagorje ob Savi, Slovenia.
